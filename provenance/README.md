# Source credits

FedSER's model, preprocessing and training code adapt Vasileios Tsouvalas's
research implementation. The six files in `original/` preserve the source at
commit `dbfb6f3da8ada7ef4a63033d77ea10f446cb7091`; `manifest.json` records their
paths and SHA-256 checksums. Install and run the `fedser` package using the
[root instructions](../README.md).

The author is Vasileios Tsouvalas. A software license has not been specified;
contact the author for reuse terms. The paper, IEMOCAP, TensorFlow and Flower
retain their respective terms.

The [method guide](../docs/method.md) describes the model, data processing and
configuration modes.
